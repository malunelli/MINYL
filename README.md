# MINYL — Música que fica 🎵

## Sobre o projeto

A MINYL é um website desenvolvido como projeto acadêmico, inspirado no universo dos discos de vinil e na estética retrô. A proposta é apresentar uma loja virtual fictícia de discos, proporcionando uma experiência visual agradável e interativa aos visitantes.

## Funcionalidades

- Página inicial com apresentação da MINYL.
- Catálogo de discos com opções de pesquisa e filtragem.
- Teste de personalidade musical com recomendações de álbuns.
- Sistema de favoritos.
- Cadastro e login de usuários.
- Área administrativa para cadastrar, pesquisar e excluir usuários.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage e SessionStorage
- GitHub Pages
